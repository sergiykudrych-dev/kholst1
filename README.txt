ХОЛСТ ДЛЯ ДВОИХ — настройка за 10 минут

1. Firebase: откройте console.firebase.google.com, войдите через Google,
   нажмите «Создать проект» (Google Analytics можно отключить).
2. Слева: Build → Realtime Database → «Создать базу данных».
   Регион любой, режим «locked mode».
3. Вкладка «Правила» (Rules) — вставьте и нажмите «Опубликовать»:

   {
     "rules": {
       "rooms": {
         "$room": { ".read": true, ".write": true }
       }
     }
   }

   Доступ есть только у тех, кто знает ссылку комнаты (длинный случайный код
   после #room=), поэтому не публикуйте её открыто.
4. Шестерёнка → «Настройки проекта» → «Ваши приложения» → значок </> (Web)
   → зарегистрируйте приложение → скопируйте значения firebaseConfig в файл
   firebase-config.js. Если в конфиге нет databaseURL — скопируйте адрес
   из верхней части страницы Realtime Database (https://....firebasedatabase.app).
   apiKey в веб-приложении не секрет, защищают правила из шага 3.
5. Опубликуйте сайт: откройте app.netlify.com/drop и перетащите туда папку
   с файлами. Чтобы сайт не удалился, войдите в аккаунт Netlify.
6. Откройте сайт, нажмите кнопку «Ссылка для двоих» и отправьте ссылку.
   Всё, что рисует один, появляется у другого.

Проверить можно и без публикации: откройте index.html в двух вкладках,
скопируйте адрес с #room=... из первой во вторую.

ФАЙЛЫ: index.html — главная («Во что сыграем?»), paint.html — игра «Холст».
word.html — игра «Угадай слово».
number.html — игра «Угадай число».
Холст (paint.html) теперь один файл: style.css, script.js и sync.js больше не нужны.
egg.html — игра «Не урони яйцо».
chips.html — игра «Чипсы-сюрприз».
tictactoe.html — «Крестики-нолики» (3 или 5 в ряд). chips.html теперь 16 чипсов на общем поле.
memory.html — игра «Найди пару» (поле 4×4, 8 пар).
monster.html — игра «Создай монстра» (5 шагов по очереди).
profile.js — имя и аватарка игрока (хранятся в телефоне и в комнате). firebase-rules.txt — правила базы и порядок включения.
friends.js — друзья (код, запросы, приглашения) на главной.
Сохранение профиля через Google: кнопка в окне «Друзья» (нужен включённый Google в Firebase Authentication и домен сайта в Authorized domains).
stats.js — статистика (история партий, счёт с друзьями). Правила базы: firebase-rules.txt.
analytics.js + privacy.html — статистика Google Analytics с баннером согласия. Работает, когда в firebase-config.js заполнен measurementId (G-XXXXXXXXXX).
og.jpg — картинка для превью ссылки в мессенджерах; в каждой странице есть og-теги.

panel.html — приватная панель владельца (человек за день, воронка комната→второй игрок→партия, популярные игры). Вход через Google; доступ только для почты из правил базы (stats). Ссылки на неё с сайта нет: открывайте .../kholst/panel.html
